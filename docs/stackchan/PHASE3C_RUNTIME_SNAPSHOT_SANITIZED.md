# Phase 3C 运行态快照（脱敏）

## Windows 设备

```text
DEVICE_MODEL=StackChan / M5Stack CoreS3（Phase 0 外观及 USB 证据）
DEVICE_CHIP=ESP32-S3 rev v0.2（既有只读识别证据）
DEVICE_FRIENDLY_NAME=USB 串行设备 (COM5) / USB JTAG/serial debug unit
DEVICE_VID=303A
DEVICE_PID=1001
DEVICE_COM_PORT=COM5
USB_STATUS=OK
```

PnP 唯一实例串、MAC、WLAN IP 和 SSID 不写入本快照。当前枚举确认的是 USB-Serial/JTAG 与 COM5 能见性，不等同于当前固件已开放任何 MOD API。
